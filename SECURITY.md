# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Host Master, please do not disclose the details publicly (e.g., by opening a public GitHub issue).

Instead, please report it privately. You can reach the team directly by joining the [StarBorn Exclusive Discord Community](https://discord.com/invite/4DNhRb87my) and sending a direct message to the administration.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- Affected version
- Any relevant logs or screenshots

## Supported Versions

Security fixes will generally target the latest released version.
